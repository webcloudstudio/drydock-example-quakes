FEATURE: Regions

FieldValue
Version20261025 V1
DescriptionThe regions report: event count and maximum magnitude per region derived from the place text.
Depends OnFEATURE-MagFilter.md, FEATURE-Formatting.md, FEATURE-Options.md, FEATURE-ExitCodes.md
Providesquakes regions
Consumesread_feed, extract_events, filter_events, write_csv, format_mag, parse_args

Purpose

quakes regions [--min-mag <m>] <file> reports the most active regions in a saved USGS GeoJSON file.

Trigger

Command line: ./quakes regions [--min-mag <m>] <file>. Only --min-mag is accepted.

Sequence

  1. read_feed, extract_events, and filter_events produce the kept events.
  2. region_of(place) is a pure function: the text after the last ", " (comma, space) in place; the whole place when it has none; "Unknown" when place is None.
  3. compute_regions(events) counts events and tracks the maximum magnitude per region.
  4. Rows are ordered by events descending, then region ascending by byte value (plain code point order, so uppercase sorts before lowercase).
  5. write_csv writes the complete report.

Output

Header: region,events,max_mag. One row per region; max_mag has one decimal. With no events, the output is only the header, exit 0. A region containing a comma cannot occur (the last ", " is split on), but quoting is always delegated to the csv module. Non-ASCII region names are written as UTF-8.

Reads

The saved GeoJSON file named on the command line.

Writes

Standard output only.

threshold = 5.4 pairs = [("Aland", 5.0), ("Aland", 5.4), ("Bland", 6.0), ("Cland", None), ("Dland", 5.3)] features = [] for i, (region, mag) in enumerate(pairs): features.append({ "type": "Feature", "properties": {"mag": mag, "place": "5 km S of T, " + region, "time": 1735706358208 + i, "tsunami": 0}, "geometry": {"type": "Point", "coordinates": [1.0, 2.0, 3.0]}, "id": "e" + str(i), }) doc = {"type": "FeatureCollection", "features": features} kept = [(r, m) for r, m in pairs if m is not None and m >= threshold] with tempfile.TemporaryDirectory() as tmp: path = os.path.join(tmp, "q.geojson") with open(path, "w", encoding="utf-8") as fh: json.dump(doc, fh) code, out, err = cli_runner("regions", "--min-mag", str(threshold), path) code_none, out_none, err_none = cli_runner("regions", "--min-mag", "9", path) print(out) assert code == 0 and code_none == 0 rows = list(csv.reader(io.StringIO(out))) assert {r[0] for r in rows[1:]} == {r for r, _ in kept} assert sum(int(r[1]) for r in rows[1:]) == len(kept) assert list(csv.reader(io.StringIO(out_none))) == [["region", "events", "max_mag"]] === END AC regions-min-mag-and-empty ===

User Acceptance

  • None.

Guardrails

  • Region splitting uses the last ", " only; "," without a following space does not split.
  • Ties in event count are broken by region name in byte order, not locale or case-insensitive order.
  • No region row is hardcoded; all values come from the file read.
