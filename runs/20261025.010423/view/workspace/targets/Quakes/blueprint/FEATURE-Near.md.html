FEATURE: Near

FieldValue
Version20261025 V1
DescriptionThe near report: events within a haversine great-circle distance of a point, nearest first.
Depends OnFEATURE-MagFilter.md, FEATURE-Formatting.md, FEATURE-Options.md, FEATURE-ExitCodes.md
Providesquakes near, haversine_km
Consumesread_feed, extract_events, filter_events, write_csv, format_time, format_mag, format_decimal, parse_args

Purpose

quakes near --lat <deg> --lon <deg> --radius <km> [--min-mag <m>] <file> lists the events whose distance from a point is at most the radius.

Trigger

Command line. --lat, --lon, and --radius are all required. parse_args enforces --lat in -90..90, --lon in -180..180, and --radius greater than zero; any violation or omission is a usage error (exit 2).

Sequence

  1. read_feed, extract_events, and filter_events produce the kept events.
  2. haversine_km(lat1, lon1, lat2, lon2) is a pure function on a sphere of radius 6371.0 km, with angles in radians:

h = sin^2((lat2 - lat1) / 2) + cos(lat1) * cos(lat2) * sin^2((lon2 - lon1) / 2) and d = 2 * 6371.0 * asin(sqrt(h)). Event coordinates are [longitude, latitude, depth_km].

  1. compute_near(events, lat, lon, radius) keeps events whose unrounded distance is <= radius and orders them by unrounded distance ascending, then by event time ascending.
  2. write_csv writes the report, with distance_km rounded half up to one decimal.

Output

Header: distance_km,time,mag,place,id. One row per matching event: distance with one decimal, UTC time, magnitude with one decimal, place, id. An event at exactly the radius is included. No matches yields only the header with exit 0. Places containing commas are quoted by the csv module; non-ASCII places are UTF-8.

Reads

The saved GeoJSON file named on the command line.

Writes

Standard output only.

Intent: Reported distances match an independent haversine on a 6371.0 km sphere, and only events within the radius are listed, nearest first.
Suite: scoped

import csv import io import json import math import os import tempfile

from cli.testing import cli_runner

def hav(lat1, lon1, lat2, lon2): p1, p2 = math.radians(lat1), math.radians(lat2) dphi = p2 - p1 dlam = math.radians(lon2 - lon1) h = math.sin(dphi / 2) ** 2 + math.cos(p1) * math.cos(p2) * math.sin(dlam / 2) ** 2 return 2 * 6371.0 * math.asin(math.sqrt(h))

origin = (27.72, 85.32) points = [ ("far", 35.68, 139.69), ("mid", 28.60, 87.37), ("near1", 28.80, 87.13), ("near2", 28.50, 87.35), ] features = [] for i, (name, lat, lon) in enumerate(points): features.append({ "type": "Feature", "properties": {"mag": 5.0 + i / 10, "place": "Place " + name, "time": 1736200000000 + i * 1000, "tsunami": 0}, "geometry": {"type": "Point", "coordinates": [lon, lat, 10.0]}, "id": name, }) doc = {"type": "FeatureCollection", "features": features} dist = {name: hav(origin[0], origin[1], lat, lon) for name, lat, lon in points} radius = round(sorted(dist.values())[2] + 1.0, 1) inside = sorted([n for n in dist if dist[n] <= radius], key=lambda n: dist[n]) assert 0 < len(inside) < len(points) with tempfile.TemporaryDirectory() as tmp: path = os.path.join(tmp, "q.geojson") with open(path, "w", encoding="utf-8") as fh: json.dump(doc, fh) code, out, err = cli_runner( "near", "--lat", str(origin[0]), "--lon", str(origin[1]), "--radius", str(radius), path ) print(out) print(err) assert code == 0 rows = list(csv.reader(io.StringIO(out))) assert rows[0] == ["distance_km", "time", "mag", "place", "id"] assert [r[4] for r in rows[1:]] == inside for r in rows[1:]: assert abs(float(r[0]) - dist[r[4]]) <= 0.051 === END AC near-haversine-distance-and-radius ===
