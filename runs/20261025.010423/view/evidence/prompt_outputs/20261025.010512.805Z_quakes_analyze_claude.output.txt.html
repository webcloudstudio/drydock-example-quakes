# COMPASS: drydock Quakes Uat Case

## Compass
A command-line tool that downloads the USGS earthquake feed as GeoJSON and reports on a saved copy of it. It serves an operator who wants quick answers about recent seismic activity: how many events and how strong, the largest events, daily and regional counts, and events near a point. It exists so those answers come from a saved file the operator controls, not a live query on every question.

## Constraints
- Python 3.11 or newer, standard library only; `urllib.request` for HTTP.
- Tests run under pytest; the application provides a POSIX-compatible `bin/test.sh`.
- The deliverable is an executable named `quakes` at the application root.
- Report commands never use the network; only `fetch` does.
- Output is CSV on standard output with `\n` line endings, written with Python's `csv` module, UTF-8.

## Guardrails
- Never embed a report answer or read `sources/run.sh` from application code; every value is computed from the file given.
- Never modify, regenerate, or substitute the frozen snapshot or the supplied grader.
- A failing command writes nothing to standard output and one diagnostic line to standard error.
- `fetch` writes no file on a network error, a non-200 status, or a non-FeatureCollection body.
- Standard error is never part of the compared output.
