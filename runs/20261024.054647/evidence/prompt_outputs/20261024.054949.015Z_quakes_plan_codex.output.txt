## Purpose

This is the terminal verification story. After every implementation and test-runner story is complete, run the supplied grader from the application root. Its exit status is the acceptance verdict. The grader and frozen snapshot are staged under `sources/` and must remain unchanged.

## Verification

- Run `sh sources/run.sh` from the completed application root.
- The executable must be available as `./quakes`.
- The grader checks report behavior against its frozen snapshot and exits successfully only when every check passes.
- Do not modify application behavior or the grader as part of this verification story; fix implementation defects in their owning feature stories.

## Programmatic Acceptance

=== AC supplied-grader ===
Intent: The supplied grader passes against the completed application.

import subprocess

result = subprocess.run(
    ["sh", "sources/run.sh"],
    capture_output=True,
    text=True,
)
print(result.stdout)
print(result.stderr)
assert result.returncode == 0
=== END AC supplied-grader ===
