# FEATURE: Earthquake Summary Report

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Computes a CSV summary of earthquake events from a saved GeoJSON file. |
| Depends On  | ARCHITECTURE.md, FEATURE-CLI.md, FEATURE-EVENT-DATA.md |
| Provides    | quakes summary |
| Consumes    | event loading, magnitude filtering |

## Questions

- None.

## Purpose

Report the event count, earliest and latest event times, magnitude range and mean, and tsunami count for the events in a saved GeoJSON FeatureCollection. Apply the shared `--min-mag` filter before calculating any values.

## Workflow

1. Parse `summary [--min-mag <m>] <file>` through the CLI.
2. Load and normalize events using the shared event data behavior.
3. Exclude null-magnitude events and keep events whose magnitude is at least the selected minimum.
4. Write the summary as CSV to standard output.

## CSV contract

Header: `events,first,last,min_mag,max_mag,mean_mag,tsunami`

Write exactly one data row. Format event times as UTC `YYYY-MM-DDTHH:MM:SSZ`; magnitudes with one decimal place; mean magnitude with two decimal places, rounded half up. Count tsunami events whose tsunami value is `1`. If no events match, write `0,,,,,,0`. Write CSV with `\n` line endings using Python's `csv` module.

A failure writes no standard output and one diagnostic line to standard error. Operational file failures exit `1`; malformed command usage exits `2`.

## Programmatic Acceptance

## Purpose

# FEATURE: Earthquakes by Day

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Reports earthquake counts and maximum magnitudes for each UTC date. |
| Depends On  | ARCHITECTURE.md, FEATURE-CLI.md, FEATURE-EVENT-DATA.md |
| Provides    | quakes daily |
| Consumes    | event loading, magnitude filtering |

## Questions

- None.

## Purpose

Group qualifying events by their UTC calendar date and report each day's count and maximum magnitude.

## Workflow

1. Parse `daily [--min-mag <m>] <file>` through the CLI.
2. Load and normalize events using shared event data behavior.
3. Exclude null-magnitude events and apply the shared `--min-mag` threshold.

Operational file failures exit `1`; usage errors exit `2`. Failures produce no stdout and one diagnostic line on stderr.

# FEATURE: Events Near a Point

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Finds earthquake events within a specified haversine radius of a point. |
| Depends On  | ARCHITECTURE.md, FEATURE-CLI.md, FEATURE-EVENT-DATA.md |
| Provides    | quakes near |
| Consumes    | event loading, magnitude filtering |

## Questions

- None.

## Purpose

Find qualifying earthquake events within a supplied radius of a latitude and longitude, inclusive, and sort them by increasing distance then event time.

## Workflow

1. Parse `near --lat <deg> --lon <deg> --radius <km> [--min-mag <m>] <file>` through the CLI.
2. Validate latitude from -90 through 90, longitude from -180 through 180, and require radius greater than zero.
3. Load and normalize events using shared event data behavior, excluding null magnitudes and applying the shared magnitude filter.
4. Compute haversine distance in kilometers on a 6371.0 km sphere.
5. Include events whose distance is at most the requested radius, ordered by distance ascending, then time ascending.
6. Write matching rows as CSV.

## Distance

For event coordinates `(lon2, lat2)` and query point `(lon1, lat1)`, convert angles to radians and compute:

`h = sin²((lat2 − lat1) / 2) + cos(lat1) · cos(lat2) · sin²((lon2 − lon1) / 2)`

`d = 2 · 6371.0 · asin(√h)`

Clamp floating point `h` to `[0, 1]` before square root.

## CSV contract

Header: `distance_km,time,mag,place,id`

Format distance and magnitude to one decimal place, rounded half up; format time as UTC `YYYY-MM-DDTHH:MM:SSZ`. Use Python's `csv` module and `\n` line endings.

A successful query with no matches returns the header only. Operational file errors exit `1`; usage errors exit `2`. Failures produce no stdout and one diagnostic line on stderr.
