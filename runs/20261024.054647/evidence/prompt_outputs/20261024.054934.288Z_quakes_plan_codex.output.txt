# FEATURE: Test Runner

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Provides a POSIX-compatible command for running the project’s pytest suite. |
| Depends On  | ARCHITECTURE.md |
| Provides    | `bin/test.sh` |
| Consumes    | pytest |

## Questions

- None.

## Purpose

Provide `bin/test.sh` as the project’s standard test entry point.

## Behavior

- The script runs the project’s complete pytest suite from the application root.
- It exits successfully only when every test passes; pytest failures produce a nonzero exit status.
- The script is POSIX-compatible and does not require network access.

## Programmatic Acceptance

=== AC test-runner-exits-successfully ===
Intent: The test runner exits successfully when the project suite passes.

import subprocess

result = subprocess.run(["sh", "bin/test.sh"], capture_output=True, text=True)
print(result.stdout)
print(result.stderr)
assert result.returncode == 0
=== END AC test-runner-exits-successfully ===

- None.

- Do not modify or depend on the supplied scoring assets under `sources/`.
