# FEATURE: Largest Earthquake Events

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Lists the largest events from a saved USGS GeoJSON file. |
| Depends On  | ARCHITECTURE.md, FEATURE-CLI.md, FEATURE-EVENT-DATA.md |
| Provides    | quakes top |
| Consumes    | event loading, magnitude filtering |

## Questions

- None.

## Purpose

The `top` command reports up to the requested number of events, ordered by magnitude descending and then event time ascending.

## Trigger

Run `quakes top [--min-mag <m>] [--n <count>] <file>`.

## Behavior

- Read and filter events using the shared event-loading and magnitude-filtering behavior.
- Default `--n` to 10. A supplied count must be a positive integer; malformed counts are usage errors handled by `FEATURE-CLI.md`.
- Emit CSV with the header `time,mag,depth_km,place,id`.
- Format time in UTC to whole seconds, magnitude and depth to one decimal place, and quote CSV fields as required.
- Sort by descending magnitude, then ascending time. Return at most `n` events.
- With no matching events, emit the header and no data rows.
- On an operational failure, emit no standard output and return the operational exit status.

# FEATURE: Earthquake Events Near a Point

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Finds events within a requested haversine distance of a geographic point. |
| Depends On  | ARCHITECTURE.md, FEATURE-CLI.md, FEATURE-EVENT-DATA.md |
| Provides    | quakes near |
| Consumes    | event loading, magnitude filtering |

## Questions

- None.

## Purpose

The `near` command finds events at or within a requested radius of a point and reports them from nearest to farthest.

## Trigger

Run `quakes near --lat <deg> --lon <deg> --radius <km> [--min-mag <m>] <file>`.

## Behavior

- Read and filter events using the shared event-loading and magnitude-filtering behavior.
- Calculate great-circle distance with the haversine formula on a sphere of radius 6371.0 km.
- Include events whose calculated distance is less than or equal to the requested radius.
- Emit CSV with the header `distance_km,time,mag,place,id`.
- Order rows by distance ascending, then event time ascending.
- Format distance and magnitude with one decimal place; format time in UTC to whole seconds.
- With no matching events, emit the header and no data rows.
- Coordinate ranges, required options, and positive radius validation are usage behavior owned by `FEATURE-CLI.md`.
- On an operational failure, emit no standard output and return the operational exit status.
