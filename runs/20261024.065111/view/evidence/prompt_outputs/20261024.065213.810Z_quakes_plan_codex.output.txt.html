# FEATURE: Fetch

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Downloads a validated USGS earthquake feed and saves it unchanged. |
| Depends On  |  |
| Provides    | quakes fetch |
| Consumes    |  |

## Questions

- None.

## Purpose

Fetch earthquake events from the USGS FDSN event service for a requested date range and save the response as GeoJSON.

## Workflow

1. Accept `--start`, `--end`, optional `--min-mag`, and required `--out`.
2. Request `https://earthquake.usgs.gov/fdsnws/event/1/query` with `format=geojson`, the supplied start and end dates, `minmagnitude` (default `2.5`), and `orderby=time-asc`.
3. Require HTTP status 200 and a JSON GeoJSON `FeatureCollection` object with a `features` array.
4. Write the successful response body unchanged to the output file.
5. Write the fetched feature count to standard output.

The request uses the standard library `urllib.request`. The HTTP call is kept replaceable so tests can stub it without network access.

## CLI Contract

`quakes fetch --start <YYYY-MM-DD> --end <YYYY-MM-DD> [--min-mag <m>] --out <file>`

The magnitude is a decimal matching `-?[0-9]+(\.[0-9]+)?`. Invalid arguments use exit code 2. Network errors, non-200 HTTP status, and invalid response bodies use exit code 1, write no output file, and produce one diagnostic line on standard error. Success exits 0 and writes `fetched,<count>` as CSV to standard output.

## Programmatic Acceptance

=== AC fetch-success ===
Intent: A stubbed HTTP response is saved byte for byte and reports its feature count.

import json
from pathlib import Path
from cli.testing import cli_runner
import quakes

payload = b'{"type":"FeatureCollection","features":[{"id":"event-1"}]}'
expected = json.loads(payload)["features"]
output = Path("fetch-output.geojson")
quakes.urlopen = lambda request: type("Response", (), {
    "__enter__": lambda self: self,
    "__exit__": lambda self, *args: None,
    "status": lambda self: 200,
    "read": lambda self: payload,
})()
code, stdout, stderr = cli_runner(
    "fetch", "--start", "2025-01-01", "--end", "2025-01-02", "--out", str(output)
)
assert code == 0
assert output.read_bytes() == payload
assert len(expected) == 1

=== END AC fetch-success ===

# FEATURE: Summary

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Produces summary statistics for events in a saved GeoJSON FeatureCollection. |
| Depends On  |  |
| Provides    | quakes summary |
| Consumes    |  |

## Questions

- None.

## Purpose

Summarize the events in a saved GeoJSON file, optionally filtering by minimum magnitude.

## Workflow

1. Read the supplied FeatureCollection and normalize each feature into an event.
2. Exclude events with null magnitude and apply `--min-mag` to all remaining events.
3. Compute count, earliest and latest UTC event times, minimum, maximum and mean magnitudes, and tsunami count.
4. Write the result as CSV with the defined header and one data row.

`properties.time` is milliseconds since the Unix epoch; output times are UTC, truncated to whole seconds. Mean magnitude uses two decimal places rounded half up. An empty result writes `0,,,,,,0` after the header.

## CLI Contract

`quakes summary [--min-mag <m>] <file>`

Magnitude values are decimals matching `-?[0-9]+(\.[0-9]+)?`. Success exits 0, operational file or FeatureCollection errors exit 1, and malformed or unsupported arguments exit 2. A failing command writes no standard output and one diagnostic line to standard error.

## Programmatic Acceptance

# FEATURE: Top

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Lists the largest earthquake events from a saved GeoJSON FeatureCollection. |
| Depends On  |  |
| Provides    | quakes top |
| Consumes    |  |

## Questions

- None.

## Purpose

List up to the requested number of largest events, optionally filtered by minimum magnitude.

## Workflow

1. Read and normalize the events from the input FeatureCollection.
2. Exclude null magnitudes and apply `--min-mag`.
3. Sort by magnitude descending, then event time ascending.
4. Keep the first `--n` events (default 10) and write the defined CSV header and rows.

Magnitude and depth are formatted to one decimal place, with depth rounded half up.

## CLI Contract

`quakes top [--min-mag <m>] [--n <count>] <file>`

`<count>` is a positive integer. Success exits 0; unreadable or invalid input exits 1; malformed or unsupported arguments exit 2. Failures write no standard output and one diagnostic line to standard error.

# FEATURE: Daily

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Groups saved earthquake events by UTC date and reports daily totals. |
| Depends On  |  |
| Provides    | quakes daily |
| Consumes    |  |

## Questions

- None.

## Purpose

Report the number of events and maximum magnitude for each UTC date in the input file.

## Workflow

1. Read events, exclude null magnitudes, and apply the optional minimum magnitude.
2. Group matching events by the first ten characters of their UTC timestamp.
3. Sort dates ascending and compute each date's count and maximum magnitude.
4. Emit a final `TOTAL` row with overall event count and maximum magnitude.

Maximum magnitudes use one decimal place. With no matching events, the total maximum magnitude is empty.

## CLI Contract

`quakes daily [--min-mag <m>] <file>`

Success exits 0; operational file or FeatureCollection errors exit 1; usage errors exit 2. Failures write no standard output and one diagnostic line to standard error.

# FEATURE: Regions

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Groups saved earthquake events by region and reports event counts. |
| Depends On  |  |
| Provides    | quakes regions |
| Consumes    |  |

## Questions

- None.

## Purpose

Report counts and maximum magnitudes grouped by the source-defined region of each event.

## Region Rule

The region is the text after the last comma and space in `place`, or the whole place when no such delimiter occurs. A null place is `Unknown`, which is also its region.

## Workflow

1. Read and normalize events, exclude null magnitudes, and apply `--min-mag`.
2. Group by region, count events, and compute each group's maximum magnitude.
3. Sort groups by event count descending, then region ascending.
4. Write CSV with one row per region.

Maximum magnitudes use one decimal place.

## CLI Contract

`quakes regions [--min-mag <m>] <file>`

Success exits 0; operational file or FeatureCollection errors exit 1; usage errors exit 2. Failures write no standard output and one diagnostic line to standard error.
