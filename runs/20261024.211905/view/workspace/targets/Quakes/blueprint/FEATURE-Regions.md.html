FEATURE: Regions

FieldValue
Version20261024 V1
DescriptionThe regions report counts events and the maximum magnitude per region of a saved feed.
Depends OnFEATURE-MinMagFilter.md, FEATURE-ExitCodes.md
Providesquakes regions
Consumesfilter_min_mag(events, m), region_of

Purpose

quakes regions [--min-mag <m>] <file> answers which regions are most active. It reads the file, applies the magnitude filter, groups events by region, and writes one CSV row per region.

Trigger

The command line quakes regions [--min-mag <m>] <file>.

Sequence

  1. Read the file and drop events with a null magnitude (reader).
  2. Keep events with mag >= m when --min-mag is given (filter).
  3. Compute one row per region: event count and maximum magnitude (compute).
  4. Format and write CSV with the csv module, \n line endings, UTF-8 (formatter).

Output

Header region,events,max_mag. Rows are ordered by events descending, then region ascending. Region text is compared by byte value (its UTF-8 encoding). max_mag is written with one decimal place. The region of an event is the text after the last , in its place, or the whole place when there is none; a null place is Unknown, which is its own region. With no matching events only the header is written and the exit status is 0.

Reads

The saved GeoJSON file named on the command line. Nothing else.

Writes

CSV on standard output only.

=== AC regions-min-mag-and-empty ===
Intent: --min-mag restricts the regions report and an empty result is only the header with exit 0.

import csv import io import json import os import tempfile from cli.testing import cli_runner

BASE = 1735689600000

def feat(i, mag, place): return {"type": "Feature", "properties": {"mag": mag, "place": place, "time": BASE + i * 1000, "tsunami": 0}, "geometry": {"type": "Point", "coordinates": [10.0, 5.0, 10]}, "id": "ev%d" % i}

threshold = 6.0 specs = [("1 km N of T, Low", 5.0), ("2 km N of T, Low", 5.9), ("3 km N of T, High", 6.0), ("4 km N of T, High", 6.8)] features = [feat(i, m, p) for i, (p, m) in enumerate(specs)]

with tempfile.TemporaryDirectory() as tmp: path = os.path.join(tmp, "q.geojson") with open(path, "w", encoding="utf-8") as fh: json.dump({"type": "FeatureCollection", "features": features}, fh) code, out, err = cli_runner("regions", "--min-mag", str(threshold), path) print(out) assert code == 0 rows = list(csv.reader(io.StringIO(out))) kept = [m for p, m in specs if m >= threshold] assert len(rows) == 2 assert rows[1][0] == "High" assert int(rows[1][1]) == len(kept) assert float(rows[1][2]) == max(kept)

code, out, err = cli_runner("regions", "--min-mag", "99", path) print(out) assert code == 0 rows = list(csv.reader(io.StringIO(out))) assert rows == [["region", "events", "max_mag"]] === END AC regions-min-mag-and-empty ===

Guardrails

  • Region text is compared by byte value, never by locale collation.
  • No report value is embedded in code; every row is computed from the file being read.
  • A failing command writes nothing to standard output.
