FEATURE: Summary

FieldValue
Version20261024 V1
DescriptionThe summary report: event count, time span, magnitude range, mean and tsunami count.
Depends OnFEATURE-MinMagFilter.md, FEATURE-ExitCodes.md
Providesquakes summary
Consumesfilter_min_mag(events, m), format_time

Purpose

quakes summary [--min-mag <m>] <file> writes the header events,first,last,min_mag,max_mag,mean_mag,tsunami and one row. first and last are the earliest and latest event times, min_mag and max_mag have one decimal, mean_mag has two decimals rounded half up, and tsunami counts events whose tsunami equals 1. With no events the row is 0,,,,,,0. Output is written with the csv module and \n line endings; the report is computed fully before anything is written.

Programmatic Acceptance

=== AC summary-values ===
Intent: The summary row carries the count, earliest and latest time, magnitude range, half-up mean and tsunami count computed from the file.

import csv import io import json import os import tempfile from datetime import datetime, timezone from decimal import Decimal, ROUND_HALF_UP

from cli.testing import cli_runner

def iso(ms): return datetime.fromtimestamp(ms // 1000, timezone.utc).strftime("%Y-%m-%dT%H:%M:%SZ")

mags = [5.0, 5.1, 5.1] times = [1735800000999, 1735700000000, 1735900000500] tsunamis = [1, 0, 1] feats = [ {"type": "Feature", "properties": {"mag": mags[i], "place": "Place " + str(i), "time": times[i], "tsunami": tsunamis[i]}, "geometry": {"type": "Point", "coordinates": [10.0, 20.0, 15]}, "id": "ev" + str(i)} for i in range(len(mags)) ] with tempfile.TemporaryDirectory() as d: path = os.path.join(d, "q.geojson") with open(path, "w", encoding="utf-8") as fh: json.dump({"type": "FeatureCollection", "features": feats}, fh) code, out, err = cli_runner("summary", path)

print(out) print(err) assert code == 0 rows = list(csv.reader(io.StringIO(out))) assert len(rows) == 2 assert rows[0] == ["events", "first", "last", "min_mag", "max_mag", "mean_mag", "tsunami"] mean = (sum(Decimal(str(m)) for m in mags) / len(mags)).quantize(Decimal("0.01"), rounding=ROUND_HALF_UP) expected = [ str(len(mags)), iso(min(times)), iso(max(times)), f"{min(mags):.1f}", f"{max(mags):.1f}", str(mean), str(sum(1 for t in tsunamis if t == 1)), ] assert rows[1] == expected assert "\r" not in out === END AC summary-values ===
