FEATURE: Min Magnitude Filter

FieldValue
Version20261024 V1
DescriptionKeep only events with magnitude at least the --min-mag value, for every report.
Depends OnFEATURE-EventNormalise.md, FEATURE-CliDispatch.md
Providesfilter_min_mag(events, m), --min-mag option
Consumesread_events(path)

Purpose

filter_min_mag(events, m) is a pure function over the event list the reader returns. It keeps events with mag >= m, preserving order. It sits in the common pipeline (read, filter, compute, format) shared by every report command, so --min-mag means the same thing in all of them. When --min-mag is absent no filtering beyond the reader's null-magnitude exclusion happens. A --min-mag value that does not match -?[0-9]+(\.[0-9]+)? is a usage error (exit 2).

Guardrails

  • --min-mag applies to every report, never to a subset of them.
  • The comparison is mag >= m; an event equal to the threshold is kept.
  • No default threshold is applied when the option is absent.
