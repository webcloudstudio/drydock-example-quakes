FEATURE: Event Normalise

FieldValue
Version20261024 V1
DescriptionNormalise event time, date and region and provide the shared number-formatting helpers.
Depends OnFEATURE-FeedReader.md, ARCHITECTURE.md
Providesformat_time, region_of, format_mag, format_one_decimal, format_two_decimal
Consumesread_events(path)

Purpose

Turn the raw values the reader returns into the text every report writes. These are pure functions in modules under the cli package, so each is unit-tested on its own.

Interface

FunctionInputOutput
format_time(ms)integer milliseconds since the Unix epochUTC YYYY-MM-DDTHH:MM:SSZ, truncated (not rounded) to whole seconds
region_of(place)place text or Nonetext after the last , in place, the whole place when it has none, Unknown for None
format_mag(mag)numberone decimal place, so 5 becomes 5.0
format_one_decimal(value)numberone decimal place, rounded half up (depth and distance)
format_two_decimal(value)numbertwo decimal places, rounded half up (mean magnitude)

An event's date is the first 10 characters of its formatted time. Half-up rounding uses decimal over Decimal(str(value)), never float formatting.

Programmatic Acceptance

=== AC normalise-format-time ===
Intent: format_time writes UTC to whole seconds, truncating the milliseconds rather than rounding them.

import importlib import pkgutil from datetime import datetime, timezone

import cli

def find(name): mods = [cli] for info in pkgutil.walk_packages(cli.path, "cli."): try: mods.append(importlib.import_module(info.name)) except Exception: pass for mod in mods: if hasattr(mod, name): return getattr(mod, name) raise AssertionError("no function named " + name + " under the cli package")

format_time = find("format_time") for ms in (0, 1735706358208, 1735706358999, 1736211916000, 1767225599999): expected = datetime.fromtimestamp(ms // 1000, timezone.utc).strftime("%Y-%m-%dT%H:%M:%SZ") assert format_time(ms) == expected, ms === END AC normalise-format-time ===

Guardrails

  • Rounding uses decimal half up, never float formatting.
  • Time is always UTC and truncated to whole seconds, never rounded.
  • No value is embedded; every result is computed from the argument.
